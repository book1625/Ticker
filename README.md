# Ticker 節拍計時器

給練習用的小工具：一邊打節拍（節拍器），一邊倒數計時。設定好 BPM 和練習時間，按下開始就能專心練，時間到會自動停。

同一個 App 有兩種版本：

| 版本 | 位置 | 說明 |
| --- | --- | --- |
| Android | `Android/` | 原生 App，可在背景播放 |
| 網頁 | `Web/Ticker.html` | 單一 HTML 檔，用瀏覽器打開就能用 |

> BPM（Beats Per Minute）＝每分鐘幾拍，數字越大節奏越快。

兩個版本的功能、畫面與音色都刻意做成一致。

## 功能

- **設定節奏**：BPM 30 ~ 240，也有 160 / 180 / 200 / 210 / 220 快選鈕
- **設定時間**：倒數 1 ~ 180 分鐘，也有 15 / 20 / 25 / 30 / 35 / 40 快選鈕
- **大字顯示**：目前 BPM 與剩餘時間（mm:ss）
- **拍點指示燈**：BPM 數字左右各一顆綠點，一拍亮左、一拍亮右，交替閃爍
- **音量調整**：0 ~ 100% 滑桿，播放中可即時調整
- **每 5 分鐘提醒**：那一拍改播長音「叮」，讓你知道過了 5 分鐘
- **結束提示**：倒數結束連播三聲「叮」
- **暫停續跑**：暫停後再開始，從剩下的時間接著跑
- **記住設定**：關掉再打開，BPM、分鐘、音量都還在

## 聲音怎麼來的

兩個版本都**沒有使用任何音檔**，聲音是程式即時合成出來的：

- 拍點：三角波 + 起音滑音 + 不諧和泛音 + 極短噪音，聽起來像木魚
- 提醒音：2000Hz 加三倍泛音的「叮」

計時採用音訊時鐘的絕對時間對齊，長時間播放也不會越走越歪。

## Android 版

### 技術

- Kotlin + Jetpack Compose（Material 3，固定深色主題）
- minSdk 24、targetSdk 36
- 主要程式：
  - `MainActivity.kt` — 整個畫面。直向是上下排列，橫向自動變三欄
  - `MetronomeService.kt` — 前景服務，用 `AudioTrack` 合成波形並跑拍點迴圈

因為做成**前景服務**（Foreground Service，會在通知列常駐的背景服務），切到別的 App 或關螢幕都還會繼續響。通知上會寫「幾 BPM、幾分鐘後停止」，並附一顆「停止」按鈕。

### 建置

用 Android Studio 直接開啟 `Ticker/Android` 資料夾，按 Run 即可。

命令列的話，在 `Ticker/Android` 底下：

```bash
gradlew.bat assembleDebug   # 編譯
gradlew.bat installDebug    # 裝到連著的手機
```

> `local.properties` 沒有進版控，換電腦要自己指定 Android SDK 路徑。

## 網頁版

`Web/Ticker.html` 是單一檔案，HTML、CSS、JavaScript 全部寫在裡面，**沒有任何相依套件、不用安裝、不用架伺服器**。用瀏覽器打開就能用。

- 用 Web Audio API 即時合成聲音
- 用 Screen Wake Lock API 在計時中保持螢幕常亮，避免手機休眠中斷聲音
- 內嵌一段無聲音檔，用來繞過 iPhone 靜音開關讓 Web Audio 壓不到聲音
- 橫放手機時自動切成左右排版

手機要用的話，把檔案放到任何靜態空間，或用瀏覽器的「加到主畫面」。

### 注意

- 瀏覽器規定要有使用者互動才能出聲，所以**一定要先按「開始」**才會有聲音。
- Screen Wake Lock 不是所有瀏覽器都支援，不支援時螢幕仍可能自動休眠。
